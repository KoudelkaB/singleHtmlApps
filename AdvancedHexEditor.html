Hex Editor Help

File Operations

Loading: Drag and drop a file onto the main window, or click the window to open a file selection dialog.

Saving: Click the Download Modified File button. You can also drag this button directly to your desktop or a file manager to save the file.

Navigation

  • Mouse: Click and drag in either the Hex or ASCII panes to select bytes.
  • Keyboard: Use PageUp/PageDown to scroll by a full screen. Use ArrowUp/ArrowDown/ArrowLeft/ArrowRight to move the selection. Use Home/End to jump to the start/end of the file.
  • Go to Address: Click the Go to... button and enter a hexadecimal address to jump directly to that location.

Editing

The Inspector Panel at the top is the primary tool for editing. When you select bytes, it shows their interpretation as different data types.

  • Number Editing (Overwrite): To edit a number (e.g., Int32, Float64), type a new value into its corresponding input box in the inspector and press Enter. This will overwrite a fixed number of bytes at the start of your selection without changing the file size.
  • Text/Hex Editing (Replace): To edit a block of bytes, use the "Selection As" editor. Choose an encoding (UTF-8, UTF-16 LE, or Hex), type your new content, and press Enter. This will replace the entire selected block, which may change the file size.
  • Deleting: Select bytes and click the Delete Selection button in the inspector panel.

In any inspector input, press Escape to cancel an edit and revert to the original value.

Search

  • Performing a Search: Type your query, select the data type (Text, Hex, or a specific number format), and click Search or press Enter. The search runs in the background and will not freeze the application.
  • Navigating Results: After a search is complete, use the < Prev and Next > buttons to jump between found occurrences. The navigation is relative to your current position in the viewport.
  • Scrollbar Map: The thin bar on the far right provides a map of all search results in the entire file. Each tick mark represents a line containing at least one match.
