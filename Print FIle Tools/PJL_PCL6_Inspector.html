Using the Inspector

Use this viewer to inspect mixed PJL jobs and PCL XL payloads without losing the surrounding job structure.

  • Drop a print job anywhere in the full left pane or use Open File.
  • The tree keeps UEL and PJL commands visible, including PJL JOB and EOJ boundaries.
  • Only payloads selected by PJL ENTER LANGUAGE as PCL XL or PCL6 are decoded as operators and typed attributes. Other languages are shown as opaque payload nodes so the structure stays honest.
  • Use Expand All Blocks, Collapse Blocks, and Filter to navigate large jobs quickly.
  • Select a node to inspect offsets, decoded values, raw hex, and begin or end jump links. Press F1 to reopen this help and Escape to close it.
