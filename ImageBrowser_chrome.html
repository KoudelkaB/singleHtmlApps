Image Browser

Chrome-only directory browser for SVG, PNG, JPG and JPEG images. Drop a folder, reopen it later from history, and browse recursively with live filtering and zoom.

Recent Directories

Recent folders are stored with File System Access handles in IndexedDB. Click one after reload to reopen it without dropping again.
