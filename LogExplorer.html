How to use Log Explorer

Loading files Browsing Operations Profiles Selecting and copying Find Keyboard shortcuts

Loading files

Drop files into the window, open one with the 📂 button, or paste text or files with Ctrl+V. Every input is decoded to UTF-8. A dropped JSON profile bundle is imported instead of loaded.

When several files arrive together, Log Explorer asks whether to show them one after another (Concat) or interleaved row by row (Zip). When content is already loaded, it asks whether to add the new files to it (Append or Zip) or to replace it (Concat or Zip). Files opened already concatenated, for example by Show in files in File Search Manager, can be switched with Interleave rows (Zip) in the status bar. Esc cancels the load.

Each file keeps its own background tint in every stage, so its rows stay recognizable after filtering, sorting, replacing, or diffing. Hover a row to see the path of its file in the status bar. Merge sources in the app menu (☰) turns the loaded content into a single source.

Browsing

Rows are never wrapped. Scroll with the scrollbars, the mouse wheel, the arrow keys, Page Up, Page Down, Home, and End; Ctrl + wheel scrolls horizontally. Hold Shift while moving to extend the selection.

Middle click shows the previous stage at the same row, Ctrl + middle click goes forward again. The view can scroll past the start and the end of the file so the row stays under the pointer.

Operations

Operations form a pipeline in the Operations panel. Click an operation to see the file after all enabled operations from the top down to it; a disabled operation stays in the list but has no effect. When the next enabled operation after the selected one is a Filter, the lines it would keep are shown in blue.

  • Filter: keeps the lines that contain any Include text and no Exclude text. Every line of a box is one alternative, Aa makes it case-sensitive, and the colored boxes under Only in files limit the filter to chosen files.
  • Replace: replaces text in the whole stage; the searched text and its replacement can span several lines.
  • Sort: sorts rows by a value read at a column or next to a text, as text, a number, a date and time, or a duration. Rows without a readable value move together with the row above them.
  • Diff: replaces the value at a column with its change from the previous row - a number, a date and time, or a duration; for text only the changed characters stay. Reverse turns the differences back into values.
  • Extract: emits regex capture groups, fixed columns, or text between two delimiters as rows. Extracting from the whole view collects every matching value, even from one-line JSON.
  • Unique: removes duplicate rows, keeping the first occurrence or sorting the result, with trim, empty-row, and case options.
  • Join: combines all rows into one value with a delimiter, prefix, and suffix; escape sequences such as \n and \t are supported.

The Transform menu adds Extract, Unique, or Join. Collect unique values adds all three at once; configure Extract, then select Join to see and copy the final delimiter-separated value.

Profiles

The pipeline is kept automatically. The chips under Profiles switch between pipelines: New starts an empty pipeline and keeps the loaded files, Last is the pipeline from the previous session. Right-click a chip to save, rename, or delete it; drag named chips to reorder them.

Profiles are stored locally. The app menu (☰) downloads them as a JSON bundle and uploads one back; dropping a bundle into the window imports it too.

Selecting and copying

A single click selects the structure under the pointer: an identifier, a number with its unit, a decimal, an IP address, a version, a path, a URL, a GUID-like value, a date, a time, or whitespace with nearby line endings. Clicking a quote selects the quoted text; clicking a bracket, including an HTML/XML tag bracket, selects the content between the matching pair. Clicking =, ==, ===, =>, !=, <=, or >= selects the surrounding expression.

Clicking inside a selection grows it: token, content between delimiters, the delimiters, then enclosing JSON/XML/HTML structures. Ctrl+click inside shrinks it back toward the clicked part; Ctrl+click outside picks the smallest useful part, such as a GUID group or a date component. Drag to select a block; click the line numbers to clear the selection.

Ctrl+C copies the selection. The app menu (☰) also copies the whole view, a column (the selection width across all rows), or a block (the selected rectangle). With several files loaded, double-click a row to add a filter that keeps only its file.

Find

Ctrl+F opens search in the current file view. Enter or F3 goes to the next match, with Shift to the previous one; Aa toggles match case. Ctrl+F3 searches for the selected text. Matches are selected and scrolled into view.

How should the new files be loaded?

Add to current

Append puts them after the loaded rows, Zip interleaves them row by row.

Replace current

Close the loaded content and show only the new files.

Zip leaves a row empty where a file has no more rows. Esc cancels.
